# Informatikai hálózat- és alkalmazás-üzemeltetés – Vizsgaremek

## Projekt bemutatása

A projekt egy valós vállalati környezet alapján elkészített hálózati prototípus, amelyet Cisco Packet Tracer segítségével valósítottam meg.

A hálózat egy gépészettel foglalkozó vállalkozás informatikai infrastruktúráját modellezi. A földszinten található a gépészbolt három munkaállomással és a számlázáshoz használt szerverrel. Az emeleten a tervezéssel és projektkivitelezéssel foglalkozó munkatársak munkaállomásai találhatók.

A hálózat része továbbá egy webszerver, közös hálózati nyomtató, valamint egy vezeték nélküli hálózat a tárgyalóban.

## Főbb megvalósított technológiák

- VLAN-ok
- IPv4 és IPv6 címzés
- Inter-VLAN routing
- HSRP
- EtherChannel
- DHCP
- WLAN
- Cisco ASA tűzfal
- statikus útvonalak
- dinamikus NAT/PAT

## A repository tartalma

A repository tartalmazza:

- a Cisco Packet Tracer hálózati projektet (`.pkt`)
- a projekt dokumentációját (`.pdf`)
- a hálózat bemutatását és működésének tesztelését tartalmazó videót
- a projekthez kapcsolódó további fájlokat
